# Minitel AutoConnect for iPhone — Support

For help with the iPhone app, email [ludovicpuaud1@gmail.com](mailto:ludovicpuaud1@gmail.com).

The app works only with the EMSE portal on the Wi-Fi name you configure. It cannot guarantee a fixed background refresh time because iOS schedules background work. To read the Wi-Fi name, allow precise location; for background checks, allow Always location access and enable Background App Refresh.

See the [privacy policy](PRIVACY.md).
